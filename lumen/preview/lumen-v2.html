Variants

Ink: the one main action. Plain: every other action. Quiet: low-weight actions in rows. Tint: a link-like action. Danger: stop or delete.

Guide book

One reading column near 65 characters. Callouts are tinted wells. Code sits in a recessed well.

Chapter 3 · Traces

Follow one request through four services

A trace records the path of one request. Each hop adds a span with a start time, a duration and a status.

In short

Metrics count events. Traces show the path of one request.

The SDK adds a traceparent header to every outgoing call. The next service reads it and continues the same trace.

otel.config.ts
export const sampler = new TraceIdRatioBasedSampler(0.1)
// keep every error trace
export const keepErrors = (span) => span.status.code === SpanStatusCode.ERROR
Good to know

At 400 spans per second, the queue holds about 5 seconds of spans.
